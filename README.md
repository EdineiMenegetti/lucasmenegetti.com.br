# Lucas Menegetti #41 · Projeto Roda a Roda

Site oficial do piloto Lucas Menegetti: trajetória, conquistas, galeria e patrocínio via Lei de Incentivo ao Esporte.

Publicado em **https://lucasmenegetti.com.br** pelo GitHub Pages.

## Estrutura
- `index.html`: o site inteiro (HTML, CSS e JS em um arquivo)
- `media/`: fotos, vídeos, troféus (`media/trofeus/` e `media/trofeus/hd/`)
- `CNAME`: domínio personalizado

## Como incluir um troféu
1. Salve a imagem sem fundo em `media/trofeus/` (420×480) e em `media/trofeus/hd/` (até 1500 px), no formato `.webp`.
2. Use o padrão de nome `MM-AAAA_sigla_etapaN_resultado[_categoria]`, por exemplo `05-2026_csmk_etapa1_1lugar`.
3. Acrescente o nome na lista `TROFEUS` dentro do `index.html`.
